# Daily Emails: a Terraform learning project

A small personal project for learning Terraform by building a daily email service.

## System

![Daily email system diagram](daily-emails.png)

## Goals
- Learn how to define and deploy cloud resources with Terraform.
- Understand how scheduled serverless applications fit together.
- Practice keeping infrastructure configuration organized and repeatable.


## What I Learned
- Terraform makes infrastructure changes reproducible and easier to review.
- Variables let one configuration work with different personal settings.
- Cloud permissions and scheduled jobs need deliberate, least-privilege setup.
- A virtual network is only needed when an application must reach private resources.


## Next Steps
- Add automated tests and deployment checks.
- Move personal settings into a safer configuration workflow.
- Experiment with new email content and schedule options.
